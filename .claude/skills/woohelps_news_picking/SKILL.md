# Woohelps 新闻挑选（按用户喜好）

## 先定受众和盘子

- 面向加拿大华人社区选新闻，覆盖加拿大所有城市，不局限于某一个城市。

- 萨斯卡通和萨省内容与用户本人相关，相关度明显高时加权，但不要因此漏掉全国大事。

- 每天选 5 到 7 条最重要的。当天确实没有足够大事时宁少勿滥，选 3 到 4 条并说明今天大事不多。

- 平台官方账号的历史发文是口味的第一参照系。本文件的正清单和负清单已按历史发布画像校准，画像与清单冲突时先按清单执行并把冲突记进优化记录。

## 历史发布画像（2026-11-03 草案依据）

- 统计口径是平台文章接口拉到的全国加全球范围已发布文章共 3718 篇，时间跨度 2018 年 1 月到 2026 年 11 月，其中官方账号海外新生活发了 3115 篇，约占八成四，是编辑口径的主体。

- 官方账号近期保持每月几十篇的更新，2026 年 5 月单月 112 篇。新闻线不是新栏目，是把这条既有编辑线自动化。

- 按标题关键词粗分，银行金融税务约 14%，房产房贷利率约 8%，移民留学签证约 7%，就业工资生意约 6%，医疗健康约 5%，教育学校约 4%，其余多为本地生活、社会安全和消费类新闻。

- 官方标题 98% 为中文，平均约 30 字，约一半带具体数字或金额。风格是完整的民生新闻句，不是干巴巴的政策播报，可以有适度情绪词，但数字和事实必须实。

- 官方常发的题材比政策播报宽，银行收费与诈骗、房贷续贷、产品召回、重大治安事件都在常发之列。挑选时按这个宽度执行，不要只盯着政策新闻。

- 发布账号最近三篇是真人编辑亲手发的现行样本，权重高于历史批量数据，选题和标题风格先向它们看齐。加拿大 2026 至 2028 移民水平计划讲配额大砍和学签减半，BMO 因超额收费被罚款 400 万加元，买房不再是从前的印钞机了讲房贷再融资收紧。

## 信息源

- 以 CBC News、CTV News、Financial Post、Daily Hive Canada 四家为主挑选，其他来源只用来交叉核实，不替代这四家凑数。

- 四家站点常无法直接抓取全文。先按站点加当天日期加关键词检索，再尽量读到原文页核实。

- 核不到原文时在条目里写清据哪家报道，并给检索到的链接。不要用搜索聚合站的转述冒充原文。

- 四家当天都覆盖不足时，如实说明覆盖缺口，不要编造链接、数字或日期补齐。

## 要选的（喜好正清单）

- 移民政策优先，包括 IRCC 新政、Express Entry 抽分和类别调整、LMIA、学签和工签、省提名、入籍，以及移民配额和水平计划。

- 房价与房贷优先，包括央行利率决议和预告、固定与浮动利率走向、房贷续贷与再融资环境、CREA 和 CMHC 数据、外国买家政策。

- 银行与消费者权益优先，包括银行收费变化、监管罚款、诈骗与假钞、账户纠纷和消费者维权结果。这是官方账号历史上发得最多的一类。

- 就业与经济优先，包括就业数据、通胀、油价，以及加美贸易和关税进展。

- 税费与福利优先，包括报税规则变化、儿童福利和其他福利、牙科福利、最低工资调整、各类补贴的申领条件变化。

- 教育与医疗要选，包括学费和学签配额、学校和医院的实质变化、药品价格与新药、重要健康研究结论。

- 公共安全要选两类，一是极端天气和出行安全预警，二是影响面大的治安事件，包括与华人社区或主要城市相关的入室抢劫、枪击和重大事故。

- 消费安全要选，包括食品和儿童产品召回、信用卡收费规则变化、信用评分规则与常见误区。

- 萨省和萨斯卡通本地大事要选，包括省政府政策、市政决定和本地突发事件。

## 不选的（负清单）

- 跳过纯娱乐八卦和名人新闻。

- 跳过与华人生活无关的远方地方小新闻。

- 跳过商家自发的生意出售和转让广告，这类是平台的商业信息，不是新闻线要选的内容。

- 跳过与近几天已选内容重复的旧闻和跟进碎片，除非有实质新进展并在条目里点明新在哪里。

- 跳过无实质信息的预告和表态，包括没有数字、没有日期、没有决定内容的喊话。

- 跳过纯观点评论，除非评论本身成了新闻事件且多家在报道。

## 排序和去重

- 同一事件多家报道时只保留一条，选信息最全、数字最扎实的一家，其他家只作核实。

- 按对在加华人生活的实际影响排序，已经宣布或已经生效的排在预期和传闻前面。

- 文案里分清已宣布或已生效与预期、传闻、分析预测，不把预测写成事实。

## 核实纪律

- 每条的数字、日期和政策生效时间都来自当天检索到的报道原文，写清数据口径和发布时间。

- 不确定的写待核实，绝不补编。

- 英文标题译成中文标题，不照抄英文。标题写成完整的中文新闻句，尽量带关键数字或金额，长度以约 30 字为参考。每条配 2 到 3 句中文摘要，说清发生了什么和对在加生活有什么实际影响。

## 成稿标准（编译与排版）

- 体裁是完整编译，不是摘要：以来源原文为骨架全文编译，信息尽量不落。篇幅随原文走：短讯 500 到 700 字，常规新闻 1000 到 1600 字，政策与数据类长文可到 2000 字以上并配表格。

- 数字、日期、人名、机构名全保留，不做有损压缩。每篇至少保留 1 到 2 处直接引语，带说话人姓名与头衔。

- 长文用「一、二、三」中文数字分节；关键专有名词首次出现标英文原文，如临时外国工人项目（Temporary Foreign Worker Program, TFWP）。

- 成稿前必须打开来源原文读全文，不许只靠搜索结果摘要拼稿；核不到原文全文的选题宁可不选。

- 排版只用平台富文本的白名单词汇，与真人编辑器产出的格式一致：正文每段套 font-size 18px；分节标题用 h2 加 color rgb(28, 72, 127) 加粗 18px，二级标题用 h3 加粗；重点数字与名词用 strong 或 b 加粗；节与节之间用 hr 分隔；文末来源行用 12px 灰色（#888888）小字。

- 内联样式只用展示端 sanitize 白名单放行的属性：color、background-color、font-size、font-weight、font-style、line-height、text-align、text-decoration、white-space。border、padding、margin、border-radius、max-width 等不在白名单、展示时会被剥掉，不要用。依据代码：主站 website/app/globals.css 的 .sanitized-html 规则与 website/app/[city]/[tag]/[postId]/details/_lib/sanitize.ts 白名单；编辑器字号映射见 website-usercenter/components/WangEditorClient.tsx（font size 4 对应 18px）。

## 发布口径

- 新闻发成平台文章，接口细节与字段以 src/publisher/news.py 和 scripts/publish_news.py 为准，日报里的链接以发布核验结果为准。

- 每条新闻必须配封面图，两级取图：优先用来源原文页的主图直链，写进发布稿的 cover_image_url，发布时自动转存平台图床；原文没有合适图片时，按文章内容生成一张封面图（插画或示意风格，不仿冒真实新闻照片，不出现可识别的真实人物面孔）。候选清单里逐条标注封面图是原文图还是生成图；两级都拿不到的选题原则上不入选。

- 平台没有单独的新闻分类，按题材选文章分类。移民留学 id 66，房产资讯 id 816，理财金融 id 818，教育文化 id 819，生活百科 id 820，商业就业 id 821，就业信息 id 3757。

- 国家 id 已实测核对，加拿大为 3。全国性新闻不带城市，全国可见。只关乎一座城市的新闻带该城市 id，城市 id 以城市接口返回为准。

- 真人编辑目前仍在不定期手工发新闻。每天发布前先看一遍发布账号最近的文章，当天真人已发的同一事件不要重复发，选题撞上时换角度或直接跳过，并在日报里注明避让了哪条。挑选开始时查一次不算数：正式发布前必须再查一次最新文章列表，确认没有其他发布者（真人编辑或其他自动流程）刚刚发过同一选题，再动手发布。

## 交付和日报

- 给用户的精选按既有格式交付，开头一行写海外新生活今日精选和日期，每条带类别、中文标题、摘要和来源链接，最后给编辑提示，点明哪条最值得优先发和临近的关键日期。

- 先选后发（2026-11-03 用户改定，取代原试点期直接发布）：每天只交付候选清单，不直接发布。清单逐条编号，列标题、分类、一句摘要、来源和封面图有无，并报跳过候选数与原因类别、避让了哪些已发文章。用户回复编号勾选后，才逐条发布被选中的稿件、核验，并回一份带平台链接的发布清单。未被勾选的条目不发布。

- 这一条长期有效，除非用户再次明确改定，不要自行恢复直接发布或全自动。

## 持续优化（喜好怎么进化）

- 用户的喜好只以本文件的正清单和负清单为准。用户给出反馈时，比如某类要多选或少选、某条不该选、某条漏了，在同一次对话里就改本文件对应的条目，不等以后。

- 每次因反馈改动后，在本节末尾的优化记录里追加一行，写日期、改了什么、依据用户哪句反馈。只改受影响的条目，不重写整个文件。

- 新反馈与既有条目冲突时，以用户最新表态为准，并把替换关系写进优化记录。

- 拿不准一条反馈是长期喜好还是一次性意见时，先问用户一句再落文件，不把一次的随口评论写成长期规则。

- 优化记录：
  - 2026-11-03 建档。初始口径来自每日新闻精选任务自 2026-10-22 以来的执行标准。用户同时定下发布试点期一到两周、日报逐条列标题加链接、新闻线覆盖加拿大所有城市。
  - 2026-11-03 草案修订（待 Min 过目）。按用户指示拉取平台已发布文章 3718 篇做画像，据此新增历史发布画像一节，正清单补入银行与消费者权益、重大治安事件、消费安全三类，负清单补入商家生意出售广告不选，新增发布口径一节。
  - 2026-11-03 试点首跑教训：新任务创建后触发当日补跑，与手动流程几乎同时发布，靠发布前复查才避开同题重复；据此把防撞规则强化为挑选前与发布前各查一次（依据：2026-11-03 首跑实测）。
  - 2026-11-03 用户确认发布账号最近三篇为真人编辑所发。画像里将其定为现行口味标杆，发布口径里新增发布前查真人最新文章避免同日同题重复的规则。
  - 2026-11-03 用户改定发布方式：以后不要直接发布，先给候选清单由用户选择哪些要发布，选中的才发；原试点期助理直接发布、日报附链接抽查的安排即日作废，交付规则与每日任务已同步改掉。
  - 2026-11-03 用户指出已发布的文章都没有图，要求配封面图；据此在发布口径里新增封面图必填规则（依据：用户原话“发布的时候我发现都没有图，应该需要配封面图”）。
  - 2026-11-03 晚讨论定稿成稿标准：用户指出助理稿件翻译太简单、排版平。对比真人三篇样本并查主站代码（.sanitized-html 规则、sanitize 白名单、编辑器字号映射）后新增「成稿标准（编译与排版）」一节；封面图补第二级规则，无原文图时生成插画风封面图。用户同时澄清从未要求「对华人影响」固定专节，该设想已撤下、不入标准。

## Websites

- [CBC News](https://www.cbc.ca/news) for 全国和各省要闻、移民与公共政策的一手报道。带当天日期和关键词进检索，尽量打开原文页核数字。

- [CTV News](https://www.ctvnews.ca/) for 突发、天气、公共安全和各省本地大事。核实事件时间和地点。

- [Financial Post](https://financialpost.com/) for 利率、房价、就业和通胀等财经口径。分清数据发布与分析预测。

- [Daily Hive Canada](https://dailyhive.com/canada) for 城市生活面新闻和本地话题。留意内容偏轻，只在与华人生活相关时选。
