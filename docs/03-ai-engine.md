# AI 处理引擎设计

## 概述

AI 引擎负责将英文活动信息转化为适合海外新生活平台的中文内容。使用 Claude API 实现以下功能：

1. **翻译**: 英文标题、描述翻译为中文
2. **摘要生成**: 从活动描述中提取关键信息，生成简洁中文摘要
3. **分类**: 将活动分类到平台对应的类型
4. **质量评估**: 评估活动是否适合平台发布

## AI 模型选择

| 任务 | 模型 | 说明 |
|------|------|------|
| 翻译 + 摘要 | Claude Sonnet | 性价比高，翻译质量好 |
| 分类 | Claude Haiku | 简单分类任务，速度快成本低 |

## Prompt 设计

### 翻译 + 摘要 Prompt

```python
TRANSLATE_PROMPT = """你是一个专业的英中翻译，专门为加拿大华人社区平台翻译活动信息。

请将以下英文活动信息翻译为中文，并生成一个简洁的活动摘要。

要求：
1. 标题翻译要简洁有力，适合作为活动标题
2. 描述翻译要保留关键信息（时间、地点、费用、参与方式等）
3. HTML 内容翻译时保持 HTML 标签结构不变
4. 摘要不超过 200 字，突出活动亮点

输入活动信息：
标题: {title_en}
描述: {description_en}
HTML内容: {html_en}
地址: {address}

费用: {price_info}

请以 JSON 格式输出：
{{
    "title_zh": "中文标题",
    "description_zh": "中文摘要（200字以内）",
    "html_zh": "翻译后的HTML内容",
    "highlights": ["亮点1", "亮点2"]

"""
```

## 批量处理策略

为了减少 API 调用次数和成本：

1. **批量翻译**: 一次请求翻译多个活动（最多 10 个），减少 API 调用
2. **缓存**: 相同内容的翻译结果缓存到本地，避免重复调用
3. **并行处理**: 不同城市的活动可以并行处理

## 处理流程

```
RawActivity (英文)
    │
    ├── 1. 质量评估 (Haiku)
    │      └── 不适合 → 标记为 skipped
    │
    ├── 2. 翻译 + 摘要 (Sonnet)
    │      ├── title_zh
    │      ├── description_zh
    │      └── html_zh
    │
    ├── 3. 分类 (Haiku)
    │      └── type (1-6)
    │
    └── ProcessedActivity (中文, 可发布)
```

## 成本估算

以每月 1000 个活动计算：

| 任务 | 模型 | 单次 Token 估算 | 月成本估算 |

| 分类 | Haiku | ~500 in + 50 out | ~$1/月 |
